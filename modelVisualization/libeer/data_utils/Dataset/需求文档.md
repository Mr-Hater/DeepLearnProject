## 1 引言

### 1.1 项目背景

脑电信号（EEG）是衡量脑部活动的一种重要生物电信号。随着情绪识别、脑机接口等领域的迅速发展，对EEG信号的分析和处理需求不断增加。SEED 数据集作为情绪识别领域的重要数据集，包含了多名被试在观看情绪视频时的 EEG 数据。

SEED 数据集存储在 **MAT** 格式中，数据结构复杂，直接分析较为困难。因此，开发一个 **EEG 数据分析系统** 来进行数据的浏览、分析和可视化变得至关重要。

本项目开发的 **EEG 数据分析系统**，能够帮助用户轻松浏览、分析 SEED 数据集中的 EEG 信号，并且支持情绪标签的统计分析、多 Session 数据对比、频谱分析等功能。

### 1.2 项目目标

本系统的目标如下：

1. 支持 SEED 数据集的读取、浏览、处理与分析。
2. 提供 EEG 信号的可视化分析，包括时间序列图、PSD 图、Topomap 脑电拓扑图等。
3. 支持情绪标签的统计与分析。
4. 支持多 Session 数据的对比分析。

### 1.3 系统范围

本系统支持以下功能：

#### 数据管理功能

- **数据集浏览**
- **MAT 文件浏览**
- **Trial 选择**

#### 信号分析功能

- **EEG 时间曲线图**
- **EEG 热力图**
- **PSD 功率谱分析**
- **Topomap 脑电拓扑图**
- **稳定区检测**

#### 特征分析功能

- **ExtractedFeatures 读取**
- **特征可视化**
- **特征热力图**

#### 统计分析功能

- **情绪标签读取**
- **情绪分布统计**
- **Session 对比分析**

### 2.2 系统架构

系统采用 **B/S 架构（Browser / Server）**：

```text
Browser
   │
   │ HTTP / AJAX
   │
Layui + ECharts
   │
   │ JSON
   │
Django Backend
   │
   │
Python EEG Analysis
   │
   │
SEED Dataset (.mat)
```

**系统流程：**

1. 用户通过前端界面选择数据集、MAT 文件和 trial。
2. 前端通过 AJAX 请求后端接口，获取数据。
3. 后端处理数据并返回 JSON 格式的数据。
4. 前端用 **ECharts** 渲染图表，显示分析结果。

## 3 数据集结构

### 3.1 SEED 数据集结构

SEED 数据集的目录结构如下：

```text
SEED
│
├── Preprocessed_EEG
│   ├── 1_20131027.mat
│   ├── 1_20131107.mat
│   ├── 1_20131030.mat
│   └── ...
│
├── ExtractedFeatures
│   ├── 1_20131027.mat
│   ├── 1_20131107.mat
│   └── ...
│
└── label.mat
```

#### 数据描述：

1. **Preprocessed_EEG**：存放预处理后的 EEG 数据。
   - 每个 `.mat` 文件包含一个被试的多个试验数据，每个试验（Trial）包含 62 通道的脑电信号。
2. **ExtractedFeatures**：存放提取的 EEG 特征数据，包含一些特征值如差分熵（DE）、功率谱密度（PSD）等。
3. **label.mat**：存放每个试验对应的情绪标签，位于 **Preprocessed_EEG** 和 **ExtractedFeatures** 文件夹下。

------

### 3.2 label.mat 说明

**label.mat** 的存储位置如下：

- 每个 **Preprocessed_EEG** 和 **ExtractedFeatures** 文件夹中都有一个 **label.mat**。
- 该文件包含该文件夹下所有试验的情绪标签。

数据结构：

```matlab
label = [-1, 0, 1, ...]  # 对应的情绪标签
```

### 4.2 EEG 时间曲线图

#### 功能描述

展示 EEG 随时间变化的曲线，支持三种显示模式。

#### 数据结构

```text
EEG 数据
channels × time
```

#### 显示模式：

1. **模式1**：通道叠加（所有通道显示在同一图表）
2. **模式2**：通道偏移（每个通道的曲线进行垂直偏移）
3. **模式3**：单通道模式（只显示选择的通道）

------
